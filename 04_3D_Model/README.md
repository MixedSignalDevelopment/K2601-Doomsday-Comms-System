# 3D Model

Enclosure design for the assembled Doomsday Comms System (D.C.S., SKU OS2601) board,
for mechanical fit, enclosure design, and review.

## File

- `K2601 DCS.step` —  Enclosure, **STEP (AP214)** format.

## Usage

Open in any MCAD tool that reads STEP (Fusion 360, SolidWorks, FreeCAD,
Onshape, Solid Edge, etc.). Use it to check connector and control placement
(USB-C, jog wheel, LCD window, antenna u.FL/SMA) against the enclosure.

> This is the authoritative mechanical reference for the whole board. The
> per-component 3D models referenced inside the KiCad PCB are **not** bundled
> (see [`../01_KiCad_Project/`](../01_KiCad_Project/)); this STEP file is what you
> need for mechanical work.
